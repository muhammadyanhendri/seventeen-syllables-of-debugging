One haiku about debugging, written by a program to `/output/entry.txt`: three lines in the 5-7-5 syllable shape, a cursor blinking at 3am while the log scrolls past, and a last line that turns the whole scene — the one true line was only a typo. The program validates the haiku before writing it (three lines, 5-7-5 syllables, at most 200 characters, no blank lines) and fails loudly if any check fails.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
